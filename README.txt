NOVA STUDIO — AI ROBLOX VIDEO STUDIO MVP

HOW TO RUN
1. Unzip the folder.
2. Open index.html in a modern browser (Chrome, Safari, Edge or Firefox).
3. No installation or paid hosting is required for local testing.

WHAT WORKS IN THIS MVP
- Story prompt to editable scene-by-scene storyboard (template-based, runs locally).
- Edit scene titles, visual directions and dialogue.
- Add and delete scenes.
- Upload and preview local video clips in the browser.
- Save project data in browser localStorage.
- Export a project JSON file.
- Character concept page and responsive dashboard.

IMPORTANT LIMITATIONS
This is a front-end MVP, not a connected AI video generation service.
The story builder uses local templates; it does not call an AI model.
The clip editor previews uploaded clips but does not combine/render an MP4.
Guest mode is used. Public user registration, secure login, cloud project storage,
payments, moderation, and real AI image/video/voice generation require a backend
and external services. Keep API keys on a secure server, never in browser JS.
